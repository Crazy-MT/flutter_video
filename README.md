# flutter_video_stable

一个基于 Flutter + media_kit 的本地视频播放器。

## 功能

- 本地视频播放与播放列表
- 记忆点标记与一键跳转
- 自定义控制条（横竖屏与全屏适配）
- 进度条提示与文件名展示
- 左右滑动屏幕调整进度
- 播放列表自动定位当前播放项

## 运行环境

- Flutter SDK: 3.9.2+
- Dart SDK: 3.9.2+

## 快速开始

```bash
flutter pub get
flutter run
```

## 权限说明

Android 端使用文件系统时会申请存储权限（包含管理外部存储权限），请在系统设置中授予。
